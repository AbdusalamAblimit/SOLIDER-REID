# exp049: NFC (Neighbor Feature Centralization) 测试时特征增强

## 实验配置
- 方法: NFC (from Pose2ID, CVPR 2025) — test-time feature augmentation
- Checkpoint: exp030a (PSG+GCN, seed 1234)
- 无需训练，仅修改评估流程

---

### NFC 原理
对每个特征向量，找到其 mutual top-k 最近邻（i 在 j 的 top-k 中，且 j 在 i 的 top-k 中），将这些邻居的特征累加到原始特征上。然后重新归一化。

---

### 关键观察

1. **NFC 在所有模式下都有显著提升**，尤其是 mAP
2. **mAP 与 k 正相关**：k 越大，mAP 越高，但 R1 在 k=5 附近达到峰值后开始下降
3. **推荐参数**: k1=k2=5 作为 balanced 设置（mAP 67.3%, R1 77.6%）
4. **equal_concat + NFC k=5 是目前全实验最佳组合**：67.3% mAP / 77.6% R1

### 与 Re-ranking 对比
- exp030a-eq + RR: 78.5% mAP / 78.8% R1
- exp030a-eq + NFC k=5: 67.3% mAP / 77.6% R1
- NFC 的 mAP 不如 RR，但 R1 接近，且 NFC 计算复杂度远低于 RR
