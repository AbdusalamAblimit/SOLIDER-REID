## ★★★ 最强收敛发现:同框"入侵身份泄漏"(co-present identity leakage)
**3 个独立 agent(读不同批)各自落到同一个角度**,且它正好是 reid-paper 项目自己最强的活口(D4 donor-leakage + 反事实一致性方法 6-7/10 待探针)。库 + 你自己的诊断 + 领域 gap 三方收敛。

### 核心洞察(重定义具体失败源, 非泛泛"遮挡难")
Occluded-Duke 的遮挡**大比例是"另一个行人"而非物体**。全领域(167篇)把遮挡当"信息缺失→补全(completion/pose/part/CLIP)"。**真正失败不是缺信息, 而是 target embedding 被遮挡那个人的身份污染**——一个 distractor identity 泄漏进来。这是 source-separation 问题, 与全场"补全"范式正交。**没有一篇这么做。**

### 为什么它过三堵墙 + 合获胜配方
- **重定义失败源**: co-present 入侵身份泄漏(可命名、可测), 非"遮挡难"。
- **机制链**: ①训练分布改动——把**已知身份**的另一行人 crop 合成贴到目标(入侵者 ID 仅训练期可得=外部信息源); ②对 embedding 做入侵身份的**对抗/对比抑制**(不是 gate——occluder-gate 是墙); ③可选 target↔自身 holistic 一致性。
- **★"为什么有效"中间变量**: **入侵者身份探针**——训一个 probe 从 target embedding 预测同框入侵者 ID 的准确率=泄漏量。baseline 泄漏高, 方法压到随机, 且泄漏下降与 mAP 增益相关。
- **★杀手对照(正面打 wall-2 通用增益障碍)**: (i)打乱入侵者**衣服/外观**→增益应保持(治身份泄漏非外观); (ii)**Market(无遮挡)应不涨**→证非通用正则; (iii)人遮挡 split vs 物遮挡 split→增益应集中在人遮挡。
- **测试口径**: 训练期强监督(入侵者ID)/测试期单 embedding 零外部。干净。
- **★廉价 kill-switch(一晚)**: 合成人遮挡上, 用强 baseline(Swin-Small)embedding 训入侵者-ID 探针。≈随机→强主干已抑制无泄漏可挖→kill; >>随机→有故事。

reid-paper 项目 D4 诊断**已确认 donor-leakage 人际混淆在强主干仍持续(≈3×物体干扰)**——kill-switch 其实已经过了。衍生"donor-leakage 反事实一致性"方法 6-7/10、待探针。**库读证明: 你这条自己的活口, 正好是整个领域的空白。**

### 诚实风险(必须先核对)
- 与红蓝队判死的"主要人物归属/target ambiguity"**相邻**。区别(待验证): 这版=纯训练端抑制 + 可测泄漏变量 + Market 负对照 + 入侵者是真实行人身份, 不是测试期归属(那破坏单 embedding)。**开工前必须翻当年判死的确切理由**(redteam_final / next_direction_after_oc4 / diagnostic_suite)。
- 与 KPR 边界(D3: 76%增益来自多人"找哪个")要划清——这版治"身份污染"非"找哪个"。
- 不能加逐像素 token-membership / 空间掩码损失(回 mask 监督死区)。
