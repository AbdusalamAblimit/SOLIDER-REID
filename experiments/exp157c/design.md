# 实验 exp157c: 梯度概率遮挡（Bottom-Heavy Gradient Occlusion）

## 动机
消融实验：比较不同遮挡策略。

策略对照：
- ROA (exp058): 画面随机位置 — 已有 61.8%
- PLBOA (exp157): 只遮挡下半身 — 本地在跑
- **exp157c**: 从下到上概率递减的遮挡 — 本实验

## 技术方案
- 对整个人体（从头到脚），下半身被遮挡概率更高
- 具体：遮挡位置 y ~ 概率正比于 (y - head_y) / (foot_y - head_y)
- 即越靠近脚部，越可能被遮挡；但上半身也有小概率被遮挡
- 使用真实 VOC 物体，p=0.7

## 与 exp157 的区别
- exp157: 严格只遮挡 hip 以下
- exp157c: 全身都可能被遮挡，但下半身概率更高
