## 最终结论

### 结果总结
- **最佳 epoch**: E110 — mAP **60.0%**, R1 **71.0%**, R5 83.3%, R10 87.3%
- **E120 最终**: mAP 59.9%, R1 70.9% (微降，cosine schedule 尾部正常)
- 这是 equal_concat (global+GCN 骨架特征拼接) 的结果

### vs 对照组
| 对比 | mAP | R1 | 差值 (mAP/R1) |
|------|------|------|----------------|
| Baseline (exp000) | 56.6% | 66.5% | **+3.4% / +4.5%** |
| PSG-only (exp007) | 58.3% | 67.9% | **+1.7% / +3.1%** |
| PDS+StopGrad global (exp023-g) | 59.5% | 69.5% | **+0.5% / +1.5%** |
| PDS+StopGrad equal_concat (exp023-eq) | 57.5% | 66.2% | **+2.5% / +4.8%** |

### 关键发现
1. **Skeleton GCN 大幅提升了 Part 分支质量**: exp023 equal_concat 57.5% → exp030 equal_concat 60.0% (+2.5%)，说明 GCN 骨架特征远优于简单 Part Pooling 特征
2. **R1 提升尤为显著**: +4.5% vs baseline, +1.5% vs exp023-g，说明骨架拓扑特征提供了很强的互补检索信息
3. **Part 分支训练收敛更快**: id_part (0.085) 远低于 id_global (0.180)，GCN 768-d 聚焦特征比分散的 GAP 更容易学习
4. **超越 exp023 global-only**: 这意味着 GCN Part 分支的 concat 提供了真正的增益，不像 exp023 的 Part Pooling 拖累 global

### 重要注意事项
- 结果中 mAP 60.0% 是 **equal_concat** (global feat + skeleton feat)，需要后续单独测试 global-only 来公平对比 exp023
- PDS 架构中 global loss 隐式乘 0.5 (list-loss 效应)，这可能是部分增益来源，exp007a 将验证此假设
