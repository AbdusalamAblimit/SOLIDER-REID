## 最终结论

### 核心发现（出乎预料）

1. **Global mAP 60.6% 远超预期**：预期 ≈ 58.3% (exp007 水平)，实际 60.6% (+2.3%)
   - w_p=0.01 意味着 GCN loss 对 total loss 的贡献 < 1%
   - GCN 通过 `detach()` 隔离，不影响 backbone 梯度
   - 唯一解释：**训练方差**（模型初始化不同 → 随机种子链路不同 → DropPath/增强序列不同）

2. **GCN 确实未训练**：ID_part loss 从 6.69 → 5.10 (vs exp030a: 6.69 → 0.17)
   - gcn_only mAP 56.9% (vs exp030a: 58.2%)，GCN 特征几乎是噪声
   - equal_concat (60.5%) ≈ global (60.6%)，GCN 特征无贡献

3. **训练方差假说进一步强化**：
   - exp030b global (60.6%) > exp030a global (59.8%) > exp007a (59.5%) > exp007 (58.3%)
   - 这四个实验使用了不同的模型类（不同初始化），global loss 权重不同
   - 但 global mAP 的差异（58.3%–60.6%，Δ2.3%）可能主要来自训练方差
   - **多种子实验仍然是最关键的待办事项**

### 消融结论

| 消融变量 | 实验 | Global mAP | Equal_concat mAP | 解读 |
|----------|------|-----------|------------------|------|
| GCN w_p=1.0 (list-loss 0.5x) | exp030a | 59.8% | 61.1% | GCN + loss scaling |
| GCN w_p=0.01 (≈1.0x) | exp030b | 60.6% | 60.5% | GCN 无贡献，global 好 |
| 无 GCN, 0.5x scale | exp007a | 59.5% | — | 纯 loss scaling |
| 无 GCN, 1.0x scale | exp007 | 58.3% | — | PSG baseline |

**关键洞察**: exp030b global (60.6%) 甚至高于 exp007a (59.5%)，说明 single-seed 对比中 2% 范围内的差异不可信。需要多种子实验才能得出可靠结论。
