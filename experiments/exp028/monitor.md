## 最终结论

**结果**: mAP 59.3%, R1 68.9%, R5 81.4%, R10 85.4%
**对照 exp023**: mAP -0.2%, R1 -0.6%, R5 +0.1%, R10 +0.1%
**判定**: 🟡 中性偏负面（基本持平，未超越）

### 关键发现
1. **Part 收敛显著改善但测试性能未提升**: Part ID loss 从 exp023 的 ~2.0 降至 0.4，但 mAP 仅从 59.5% 微降至 59.3%
2. **Part 分支收敛不是 PDS 性能的瓶颈**: 即使 Part 完全收敛（loss < 0.5），concat 特征也没有改善
3. **过拟合的迹象**: Part 训练 loss 极低但测试性能没有对应提升，暗示 Part 分支可能在过拟合
4. **Part tri loss 全程低于 Global tri**: 说明 Part 特征在训练集上区分度很好，但泛化能力没有对应提升

### 对创新方向的启示
- Part LR 不是 PDS 的改进方向
- PDS 的瓶颈可能在于：(a) equal_concat 融合方式限制了 Part 贡献 (b) stop_grad 阻止了 Part 对共享层的反馈 (c) Part 特征与 Global 特征冗余度高
- 下一步应探索特征融合方式或双流架构的根本性改进
