先给结论：**对抗鲁棒 ReID 不是完全红海，但“通用 PGD/adv-training 防御”基本别碰**。2025/AAAI 2026 已有 Debiased Dual-Invariant Defense 把问题定义成 metric-learning 防御、unseen ID/attack 双泛化，并做重训练框架。可挖的是更 ReID-specific、低成本可证伪的物理/语义攻击侧防御。

**机会 1：Rank-Leverage 反事实防御：物理 patch 攻击不是“扰乱图像”，而是让少数局部区域劫持整个 rank**
- **触发观察/失败**：ReID 攻击主线从 advPattern 物理衣服图案、Deep Mis-Ranking，到 2024 DiffPhysBA 物理 backdoor、2024 Edge-Attack VI-ReID physical patch，都在打 rank，而不是分类边界。Deep Mis-Ranking 明确是 learning-to-mis-rank，能把强模型准确率从 91.8% 打到 1.4%；advPattern 也报告物理 evading 下 Rank-1 从 87.9% 降到 27.1%。DiffPhysBA 用包/帽子等真实物体做物理 backdoor，ASR 超 90% 且可绕过已有防御。  
  Sources: Deep Mis-Ranking CVPR 2020；advPattern ICCV 2019；DiffPhysBA 2024；Edge-Attack 2024。([arxiv.org](https://arxiv.org/abs/2004.04199)) ([arxiv.org](https://arxiv.org/abs/1908.09327)) ([arxiv.org](https://arxiv.org/abs/2405.19990)) ([arxiv.org](https://arxiv.org/abs/2410.20097))
- **重定义**：不要问“模型能否识别被攻击图像”，而问：**一个 query 的 top-k ranking 是否被局部小区域支配**。正常身份证据应分散在多区域；物理攻击/trigger 会形成高 rank-leverage 区域。
- **机制草案**：零训练版先做 `Counterfactual Rank Voting`：对 query 做网格/人体区域局部 erase 或 blur，跑 frozen SOLIDER/Swin 特征，统计每个区域删除前后的 top-k Jaccard、rank entropy、top-k distance shift。高 leverage 区域被判为可疑；最终检索用低 leverage 反事实视图的 median/trimmed score。训练版再做 `Rank-Leverage Suppression`，把高 leverage 区域作为自动 hard erasing，约束 rank 在局部删除下稳定。
- **廉价 kill-switch**：不用训练。
  1. Market/MSMT 上跑 frozen baseline。
  2. 用 Deep Mis-Ranking 代码或简单局部 EOT patch 生成 query attack。
  3. 指标：clean mAP/R1 下降必须 <1%；attacked query 检测 AUC >0.75，或恢复至少 30% 被攻击损失。
  4. 加 occlusion 控制：同面积灰块/blur 也能造成同样 rank-leverage，则说明只是遮挡老问题，kill。
- **撞车核查**：2024-26 检到的是 DiffPhysBA、Edge-Attack、DDI Defense；没检到“rank-leverage / rank counterfactual consistency” 作为 ReID 防御主问题。DDI 是重训练 adversarial defense，不是零训练 rank 诊断。([arxiv.org](https://arxiv.org/abs/2511.09933))
- **verdict**：值得先做，最像 B 类方法稿入口。  
  **信心：7/10**。  
  **数据**：Market/MSMT/occluded_duke 可首验；不需要新数据。若最终声称 physical robust，最好补一个小型打印 patch 或真实包/帽子采集集。

**机会 2：Portable-Object Robust ReID：物理 backdoor 的本质不是 patch，而是“可携带物体身份捷径”**
- **触发观察/失败**：DiffPhysBA 的关键不是高频扰动，而是用真实包、帽子等 semantic trigger 让物理世界激活 backdoor；论文还强调这种 trigger 更隐蔽，并能绕过已有 backdoor defense。([arxiv.org](https://arxiv.org/abs/2405.19990))
- **重定义**：大家默认 ReID 依赖 clothing/appearance 是合理的，但物理安全场景里，**可转移物体**，如包、帽子、手提物，不应被当成稳定身份。新问题可叫 `Portable-Attribute Robust ReID`：同一人携带物变化、不同人共享/交换携带物时，rank 不应被物体劫持。
- **机制草案**：先构造 object counterfactual benchmark：检测/分割 bag/hat/backpack，把物体从 donor 复制到 recipient，或从 query 删除。方法上做 body evidence 与 portable-object evidence 解耦：object-only 分支作为 adversary，训练时惩罚“仅靠 portable object 拉近身份”；推理时如果 query-gallery 相似度主要来自 portable-object region，则降权。
- **廉价 kill-switch**：零训练首验。
  1. 用 RSTPReid 文本关键词或开放词检测筛 bag/hat/backpack 样本。
  2. 在 Market/MSMT/CARGO 上做 copy-paste/removal。
  3. 计算 `object hijack rate`：recipient 加 donor 物体后，donor ID 是否进入 top-k；或删除物体后原 top-k 是否大幅变。
  4. 必须做控制：同 mask 灰填充、随机纹理、颜色直方图匹配。如果效果被这些 trivial 代理解释，kill。
- **撞车核查**：2024-26 直接撞到的是 DiffPhysBA 攻击侧；没检到“可携带物体鲁棒 ReID/portable-object deconfounding”作为防御或 benchmark 主线。风险是会被审稿人归到 backdoor defense 或 occlusion robustness，所以必须用 copy-paste object 控制证明它不是普通遮挡。
- **verdict**：有新问题感，但比机会 1 风险高。适合半天 cheap-kill，通过后再扩。  
  **信心：6/10**。  
  **数据**：RSTPReid 可帮筛文本含 bag/hat/backpack 的样本；Market/MSMT/CARGO 可做首验。不需要新数据做 kill-switch，成稿最好补小型真实携带物采集。

不建议做：普通 adversarial training、PGD 防御、随机擦除增强、occlusion-as-defense。ETNDNet 已把 occlusion 当 adversarial disturbance 做过，DDI Defense 又把 general adversarial ReID defense 往前推了一步；这些方向很容易变成“重训练版旧防御”。([arxiv.org](https://arxiv.org/abs/2307.07187)) ([arxiv.org](https://arxiv.org/abs/2511.09933))
