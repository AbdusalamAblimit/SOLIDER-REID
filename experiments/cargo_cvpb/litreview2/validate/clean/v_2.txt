**Verdict**

我会替 B 辩护，但先把一句话改准：**物理信息上是“航拍证据 ⊂ 地面证据”；概率候选空间上应是“地面窄分布被航拍宽分布覆盖”**。如果继续写“航拍宽高斯 ⊆ 地面窄高斯”，reviewer 会直接抓数学矛盾。建议命名成：

> Cross-view ReID is not symmetric alignment, but **physically directed uncertainty containment**: aerial observation is an underdetermined projection whose identity-compatible ground appearances form a broader distribution; correct ground evidence should fall inside that aerial uncertainty envelope.

信心分：**7/10**。如果零训练 + 训练版都能过下面的杀手证据，能到 **8/10**；如果只靠一个 KL 分数涨点，最多 **5/10**。

**为什么 B 仍是最强赌注**

B 比 C/D 更像 B 类方法稿的“主问题重定义”。C 的“对齐伤判别性”被你们自己的结果削弱了：关键不只是 MaxSim 失败，而是 avg-pool 强，容易退化成“别做局部匹配”。D 的因果 framing 大，但 view 是否真是 confounder 很难证，容易写成大词小证据。B 至少有一个明确、可测、可证伪的隐藏变量：**视角成像导致的信息欠定度不对称**。

切开点要这样写：

- vs **PDA**：PDA 的最近邻确实很近，本地综述也写得很清楚：它把文本-图像改写为“文本分布包含图像分布”，方差是语义范围 [reviews/deep_22.md](/Users/abdslm/Desktop/SOLIDER-REID/experiments/cargo_cvpb/litreview2/reviews/deep_22.md:11259)。我们的活路不是“高斯包含没人做过”，而是**文本语义范围 → 航拍成像欠定范围**；方向不是语言粒度决定，而是相机高度、分辨率、人体投影面积决定。
- vs **probabilistic embedding / uncertainty ReID**：PCME 用概率分布处理图文一对多对应，DUL/ReID uncertainty 用后验/先验高斯建模样本不确定性；它们不是 cross-view 物理方向的包含关系。([arxiv.org](https://arxiv.org/abs/2101.05068?utm_source=openai)) ([arxiv.org](https://arxiv.org/abs/2007.08785))
- vs **OT-ReID / CM-EMD**：CM-EMD 是用最优传输做跨模态分布对齐，核心是 transport cost 和 intra-identity variation weighting；B 不能写成“更好的 OT”，而要强调**不求对齐/搬运，而是接受航拍证据欠定，用非对称覆盖打分**。([arxiv.org](https://arxiv.org/abs/2203.01675?utm_source=openai))
- vs **AGPReID 红海**：VDT 是 view-related/view-unrelated decoupling，GSAlign 是 TPS 几何 warp + visibility mask，SeCap 是 prompt recalibration + local refinement，DTST 是 token selection。B 必须避开“几何/可见性/局部选择”，把 SMPL 只用作诊断物理欠定度，不作为主模块。([arxiv.org](https://arxiv.org/abs/2403.14513?utm_source=openai)) ([arxiv.org](https://arxiv.org/abs/2510.22268?utm_source=openai)) ([arxiv.org](https://arxiv.org/abs/2503.06965?utm_source=openai)) ([arxiv.org](https://arxiv.org/abs/2412.00433?utm_source=openai))
- vs **cross-resolution ReID**：PS-HRNet/RFD 这类线主要做恢复、变换或 resolution-invariant feature；B 的说法应是“不幻想补齐不可见细节，而是显式表达候选身份范围”。([arxiv.org](https://arxiv.org/abs/2105.11722?utm_source=openai))

**最能打动 Reviewer 的杀手证据**

1. **方向性破坏对照**
   同一 frozen Swin 均值、同一调参预算，比：
   `cosine`、`symmetric KL/JS/Bhattacharyya`、`KL(G||A)`、`KL(A||G)`、`view-swapped variance`、`same variance`。  
   成立条件：**物理正确方向显著最好；反向或对称接近就推翻“非对称包含”叙事**。

2. **方差不是难度，而是成像欠定度**
   预测/估计的 `σ_A` 必须系统性大于 `σ_G`，并且和物理指标相关：aerial bbox area 小、投影人体像素少、头肩俯视比例高、blur/downsample 强时方差更大。  
   破坏对照：打乱 view 标签、打乱 σ、只用 baseline top-k entropy 作为 σ。若这些也赢，说明只是难度重权重，不是信息欠定。

3. **收益必须集中在物理欠定样本**
   按 aerial bbox area / SMPL visible surface / image resolution 分桶。  
   成立条件：最小 aerial 桶、最高俯视桶、最低可分辨桶上包含距离收益最大；ground-ground 或 high-res aerial 上收益弱。若全桶平均涨，故事变成普通 metric trick。

4. **覆盖校准图**
   对每个 aerial query 的高斯 envelope，看同 ID ground positives 是否落在 50/80/95% 覆盖区间内，并比较 hard negatives。  
   成立条件：正确 ground 的 coverage 校准好，hard negative 被排除；PDA 式“只学大方差兜底”会在这里暴露。

5. **训练版必须 beat 当前最强 avg**
   你们现在的硬观察是 `avg 52.37 > MaxSim 45.19`，这反而给 B 一个门槛：训练版不能只赢 MaxSim，必须赢 **avg 52.37**。本地记录也显示 MaxSim headline 已被 avg 强烈威胁 [validate/v_3.md](/Users/abdslm/Desktop/SOLIDER-REID/experiments/cargo_cvpb/litreview2/validate/v_3.md:403)。  
   判据建议：单 seed 至少 `+1.0 mAP` over 52.37，且低清 A→G 分桶 `+2~3 mAP`，否则不够撑主贡献。

**够不够一篇 B 类**

够，但前提是论文主贡献不能写“我们提出 Gaussian/KL”。应该写：

> We reveal a physically directed information asymmetry in aerial-ground ReID and show that symmetric alignment/late interaction is the wrong matching assumption.

方法上可以很朴素：mean + variance head、directional containment loss、physical underdetermination regularizer、containment retrieval score。体量来自**诊断证据 + 破坏性对照 + 两数据集验证**，不是模块复杂度。

我建议下一步先做增强版零训练 kill-switch：`correct-direction containment` 必须同时打赢 `cosine / symmetric distribution distance / reversed containment / shuffled variance / same-view control`。这个过不了，B 直接停；过了，再做训练版。
