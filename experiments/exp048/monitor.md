### 结论

**exp048 SGMKC 是一个明确的负面结果。**

**失败原因分析**:
1. **双任务梯度冲突**: SGMKC loss 在总 loss 中占比始终较高（30-50%），分散了 GCN 学习 ID 分类的梯度信号
2. **GCN 容量不足**: 2 层 GCN 无法同时完成 ID 分类和特征重建两个任务。重建需要保留低级特征信息，ID 分类需要丢弃低级信息
3. **重建目标与 ID 目标不一致**: 重建要求 GCN 输出接近原始特征（保持不变），但 ID 分类要求 GCN 输出对身份更具区分性（改变特征）
4. **SGMKC loss 的量级**: weight=1.0 可能过大，但这是一个连续的负信号而非偶然波动

**与 exp030a 的对照**: 本实验唯一变量是增加了 SGMKC auxiliary task。差距稳定在 -1.5~-2.0%，说明 SGMKC 确实有害。

**对后续方向的启示**:
1. 在 GCN branch 上做自监督重建类任务不可行（容量不足 + 梯度冲突）
2. 如果要做特征补全，需要独立的解码器（如 FCFormer 的 transformer decoder），而不是共用 GCN
3. 自监督辅助任务的方向本身可能不是最佳路线 — 更应该关注 retrieval-time matching 或数据增强
