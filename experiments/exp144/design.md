# 实验 exp144: SASA alpha=1.0（强骨架注意力偏置）

## 动机

exp143 SASA (alpha=0.1) 完美中性（61.1%/73.7% = exp030a）。可能的原因：
1. alpha=0.1 太弱，注意力偏置被原始 attention scores 淹没
2. 或者 Swin RPE 已经足够，骨架信息完全冗余

本实验测试 alpha=1.0（10 倍于 exp143），验证是否是偏置强度不够。

## 核心假设

如果 alpha=0.1 的骨架偏置被 attention scores 淹没（QK^T/sqrt(d) 的量级通常在 1-5），那么 alpha=1.0 应该能让骨架先验真正影响注意力分配。

## 技术方案

与 exp143 完全相同，唯一差异：`POSE_SASA_ALPHA: 1.0`

## 对照组

- exp143 (alpha=0.1): 61.1% / 73.7%（中性）
- exp030a: 61.1% / 73.7%

## 预期结果

- 如果 alpha 太弱是问题：应看到正增益
- 如果骨架信息冗余：应看到中性（再次）
- 如果 alpha 太强：应看到负面（过度约束注意力）

## 风险

alpha=1.0 可能过强，强制注意力按骨架结构分配可能限制模型灵活性
