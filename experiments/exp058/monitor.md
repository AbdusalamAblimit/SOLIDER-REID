## 最终结论

**exp058 ROA 是 PSG+GCN 框架上第一个产生超出方差的正向增益的方法！**

- mAP +1.07%（equal_concat），超出 3-seed std 0.47% 的 2 倍以上
- mAP +1.47%（global），极显著
- R1 在 equal_concat 下几乎持平（+0.23%），在 global 下显著正向（+1.13%）
- **纯数据增强，零模型参数增加，零额外 GPU 开销**
- 训练速度 56s/epoch，与 baseline 相同

### ROA 为什么有效
1. 真实物体遮挡比随机矩形更接近 Occluded-Duke 的测试分布
2. VOC 物体有自然的形状和纹理，不像 RE 的均匀噪声矩形
3. Alpha blending 产生软边缘，模拟真实遮挡的渐变
4. **关键**：ROA 同时在 global 和 branch 上都有提升，说明改善了 backbone 特征的遮挡鲁棒性
