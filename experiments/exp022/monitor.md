## 最终结论

1. **PDS global-only (57.9%) vs PSG-only (58.3%)**: Global 分支有 -0.4% mAP 损失。Part 分支通过共享 Stage 0-2 的反向传播确实对 Global 分支产生了微小干扰，但比 exp008 (57.7%) 好。
2. **PDS global-only (57.9%) vs baseline (56.6%)**: +1.3% mAP，说明 PSG 增益在双分支中大部分保留。
3. **concat_scaled (57.5%) vs baseline (56.6%)**: +0.9%，Part 特征作为辅助有贡献但被 noise 拉低。
4. **equal_concat (56.1%)**: 维度比 5:1 严重稀释 Global 贡献，不是好的 fusion 策略。
5. **Part-only (55.2%) vs baseline (56.6%)**: -1.4%，Part 分支独立特征不如 Global 分支。Part ID loss (2.02) 远未收敛到 Global (0.17) 的水平。

**核心发现**: Stage 3 权重解耦有效避免了 exp008 的严重干扰（57.9% vs 57.7%），但共享 Stage 0-2 仍存在轻微干扰（57.9% vs 58.3%）。Part 分支需要更好的训练策略才能真正贡献增量性能。

**下一步方向**:
- 尝试 Part 分支 stop_gradient 到共享层，完全隔离 Part 梯度
- 尝试 Part 分支延迟启动（先让 Global 分支收敛）
- 尝试更激进的 Part 训练（更高 LR、更长训练）
