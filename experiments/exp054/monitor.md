## 最终结论

**exp054 PGAM 是第一个在 PSG+GCN 基础上产生正向信号的训练端模块！**

### 关键发现

1. **mAP 61.1% 是单 seed 历史最高**，超越 exp030a 单 seed (60.5%) +0.6%
2. **R1 73.8% 也是最高**，超越 exp030a 单 seed (73.7%) +0.1%
3. **vs 3-seed mean: mAP +0.37%（方差范围内边缘）, R1 +1.23%（超出方差）**
4. **Global 模式完全持平**：说明 PGAM 不影响 backbone 全局特征，增益来自改善了 GCN branch 的注意力模式
5. **CVK 模式完全持平**：PGAM 的增益不影响 test-time distance 计算
6. **训练速度零开销**：55s/epoch，与 exp030a 完全相同（PGAM 零参数）
7. **mAP 趋势持续正向**：从 ep10 的 +0.1% 逐步增长到 ep120 的 +0.6%，没有后期回落

### 需要多 seed 确认

+0.37% mAP 在 3-seed 方差范围内（std ~0.47%），需要 4090 上多 seed 验证。但 R1 +1.23% 超出方差范围，是一个更强的信号。

### 为什么 PGAM 可能有效

PGAM 阻止非人体 token（遮挡物/背景）通过自注意力"污染"人体 token 的表征。虽然 PSG 已经减弱了非人体 token 的值，但在 attention 中它们仍然参与计算。PGAM 从信息流层面阻断了这种污染。两者互补：
- PSG: 减弱遮挡物特征的幅值（feature-level）
- PGAM: 阻断遮挡物的注意力参与（attention-level）
