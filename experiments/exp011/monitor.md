## 最终结论

**exp011 最终结果: mAP 58.3%, R1 67.6%, R5 81.1%, R10 85.3%**

### 与 exp007 对比
| 指标 | exp007 (120ep) | exp011 (200ep) | 差异 |
|------|----------------|----------------|------|
| mAP | 58.3% | 58.3% | 0.0% |
| R1 | 67.9% | 67.6% | -0.3% |
| R5 | 80.8% | 81.1% | +0.3% |
| R10 | 84.9% | 85.3% | +0.4% |
| 训练时间 | ~2h | ~3.5h | +75% |

### 关键发现
1. **200 epochs 不比 120 epochs 好**: mAP 完全相同，R1 甚至略低。额外的 80 epochs（+75% 训练时间）没有带来任何实质性改善
2. **PSG 的收敛上限在 mAP ~58.3%**: 无论 120 还是 200 epochs，最终都收敛到同一个水平
3. **200ep schedule 的中段过拟合更严重**: ep60-120 的 mAP 持续低于 exp007 同期（最大差距 -4.2%），需要后段 cosine decay 来恢复
4. **R5/R10 有微弱改善**: 可能是因为更长训练让特征空间更平滑（更多样本覆盖了更多的 near-miss 匹配）
5. **120ep 是 PSG 训练的最优 schedule**: 高效且性能相同

### 对论文的意义
- 不需要延长训练来提升 PSG 性能 → 方法高效
- PSG 的性能上限由架构决定，而非训练长度 → 需要架构创新来突破
