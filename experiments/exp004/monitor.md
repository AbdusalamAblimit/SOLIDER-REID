## 核心创新
**PFM（Pose Feature Modulation）**：在 backbone 特征图和 pooling 之间插入 pose-conditioned 特征调制。
- 现有方法仅用 pose 做空间选择（WHERE to pool）
- PFM 用 pose 做特征调制（WHAT to enhance/suppress）
- 两者正交，同时改善 global 和 part features

### 技术细节
- PFM: 17ch heatmap → Conv1x1(17→64) → ReLU → Conv1x1(64→768) → modulation weights
- 应用：feat_map × (1 + mod_weights)，零初始化使初始状态为恒等映射
- 参数量：~51K（极轻量）
- Global feature 从调制后的特征图 GAP 得到

## 最终结论

**exp004 PFM 是中性结果**。

### 正面
- PFM 改善了 global 特征 mAP (+0.3%)，验证了 pose-conditioned feature modulation 概念的可行性
- PFM 显著加速了中期收敛（ep20-60 领先 exp001 约 1-2%）
- PFM 没有增加 backbone 负担（零初始化 + 仅 51K 参数）

### 负面
- **Part 特征 mAP 完全没有改善**（57.5% = 57.5%）
- **R1 全面下降 0.5-0.8%** — PFM 使特征变得更"模糊"
- 加速收敛但不改善最终表征质量

### 根本原因分析
1. PFM 的 feature modulation 与 part pooling 的 spatial attention **信息冗余** — 两者都基于 pose heatmaps
2. PFM 可能使特征图上各位置的特征更加相似（modulation 的全局效应），降低了空间判别性
3. Part 特征质量的瓶颈不在 feature modulation，而在分辨率（12×4）和 part classifier 学习

### 对后续实验的启示
- **不要在同一处重复使用 pose 信息**（PFM + Part Pooling 是冗余的）
- 需要从不同角度利用 pose：空间选择 OR 特征调制 OR 结构约束，但不要叠加
- Part 特征的瓶颈在于空间分辨率，应该尝试更高分辨率的特征图

**最终指标（part-only test）**: mAP 57.5%, R1 66.3%, R5 79.6%, R10 84.1%
