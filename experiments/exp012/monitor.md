#### 结论

1. **PAB 有效但弱于 PSG**: PAB 比 baseline 提升 +0.8% mAP，但 PSG 提升 +1.7%，PAB 的效果约为 PSG 的一半。
2. **原因分析**:
   - PAB 只有 5,424 参数（PSG 102,400），容量不足可能限制了表达能力
   - Additive decomposition (bias(i,j) = val[i] + val[j]) 是 rank-2 近似，无法表达复杂的 pairwise bias
   - PAB 修改的是 attention score（softmax 前），效果被 softmax 压缩；PSG 直接在 feature 空间操作（乘法门控），效果更直接
   - Swin 的 7×7 window 限制了 attention 范围，pose bias 在小窗口内可能信息量有限
3. **关键发现**: 尽管 PAB 弱于 PSG，但它证明了 pose 信息确实能有效影响 self-attention。如果能用更强的 attention 调制方式（如 cross-attention 或可学习的 pairwise bias），可能超越 PSG。
4. **论文价值**: PAB 作为消融实验很有价值——展示"attention-level 注入弱于 feature-level 注入"，支持 PSG 设计的合理性。
