# exp103: ROA+SGMT 组合 (实际执行) / PGCE (原计划未实现)

**注意**: 原计划是 PGCE (跨图人体遮挡)，但实际执行的是 ROA+SGMT 组合实验。
该组合实验在 Ep1 被用户要求停止（不做组合实验），PGCE 从未实现。

## 动机
- ROA (+1.27%) 是唯一有效的训练端数据增强创新
- ROA 用 VOC 物体遮挡 → 但真实遮挡主要来自其他行人
- 所有训练端模块改进（FiLM, PKP, SGMT, DPF, etc.）都中性
- **新方向**: 不改架构，改数据 — 用 pose 信息生成更真实的遮挡

## 核心想法
PGCE: 利用 batch 内其他人的 pose 信息，将其身体部位区域
用于遮挡当前人。相比 ROA (随机 VOC 物体)，PGCE 产生的遮挡
更接近真实场景（行人之间互相遮挡）。

实现:
1. 对每个训练样本，随机选 batch 内另一个人
2. 用该人的 pose heatmap 确定其身体部位区域
3. 将该人的身体区域（从其图像中裁剪）粘贴到当前人的图像上
4. 当前人的 ID 标签不变，但图像被"另一个行人"遮挡了

关键区别于 ROA:
- ROA: 粘贴无关物体 (cars, chairs, etc.)
- PGCE: 粘贴人体部位 → 更难区分 target vs distractor
