## 最终结论

**最终结果**: mAP 57.9%, R1 67.5%, R5 81.1%, R10 85.3%
**对照 exp007 (PSG-only)**: mAP -0.4%, R1 -0.4%, R5 +0.3%, R10 +0.4%
**对照 baseline**: mAP +1.3%, R1 +1.0%

**结论**: PWP（Pose-Weighted Pooling）相比标准 GAP 几乎中性，略微负面。

**分析**:
1. PWP 本质上是 PGTS 的 soft 版本（用 pose 热图的 max-channel sigmoid 作为空间权重）
2. PSG 已经在 Stage 3 blocks 内完成了空间选择（通过 feature gating），post-backbone 的 PWP 是冗余操作
3. PWP 的 body_mask = sigmoid(max(heatmaps)) 可能对非遮挡图片产生均匀权重（≈GAP），但对遮挡图片可能过度压制非人体区域，导致特征维度利用不充分
4. 训练 loss 非常低（ID 0.067, Tri 0.014）但测试 mAP 停滞，确认 PSG+PWP 有轻微过拟合倾向

**对创新方向的启示**: Post-hoc weighted pooling（包括 PGTS soft 版本）在 PSG 基础上无法提供额外收益。如果要做 token-level 操作，需要在 Stage 3 **内部** 做 hard token selection，而不是在 pooling 阶段做 soft weighting。
